📅 03 de septiembre de 2025


Recientemente completé el test del módulo de **ReactJS en** la **Academia Conquer Blocks**, dentro del máster de Desarrollo Full Stack. El test cubría conceptos clave de React, como componentes, hooks (`useState`, `useEffect`, `useMemo`, `useCallback`), gestión de estado con Context, rutas protegidas con React Router, formularios con `react-hook-form` y consumo de APIs con Axios, entre otros.

Además de responder correctamente a todas las preguntas, he desarrollado varios proyectos prácticos utilizando React para reforzar mi aprendizaje y aplicar estos conceptos en entornos reales. Podéis consultar estos proyectos en el siguiente enlace: [Proyectos React](https://jaterli.com/proyectos/tag/react/).
